# 上线说明

## 现在要上传什么？

当前官网是纯静态页面，没有后端、没有数据库、没有接口。

如果先用现在的占位作品图上线，只需要上传：

```text
index.html
```

把 `index.html` 放到你的服务器网站根目录，访问你的域名就能看到官网。

## 后面换真实作品图片时要上传什么？

如果后续把产品图换成真实图片，需要一起上传：

```text
index.html
assets/
```

图片建议放在：

```text
assets/portfolio/
```

然后在 `index.html` 的 `PRODUCT_CONTENT` 里填写图片路径，例如：

```js
image: 'assets/portfolio/knowlens.webp'
```

如果 `image` 为空，页面会继续使用当前自动生成的占位作品图，不会空白。

## 后续替换产品内容时改哪里？

只改 `index.html` 里的这一块：

```js
const PRODUCT_CONTENT = [...]
```

这里放：

- 产品名称 `title`
- 产品状态 `status`
- 首页悬停短简介 `hoverSummary`
- 点击弹层正式简介 `description`
- 产品图片路径 `image`
- 按钮文案 `ctaLabel`
- 按钮链接 `ctaUrl`

不要改 `PRODUCT_LAYOUT`，那是控制首页图片位置和动画的。

## 服务器需要什么？

服务器只需要支持静态文件访问即可。

不需要：

- Node.js
- Python
- PHP
- 数据库
- 后台管理系统
- 接口服务

## 推荐上线流程

1. 在服务器网站目录里上传 `index.html`。
2. 如果有真实图片，同时上传 `assets/` 文件夹。
3. 用浏览器打开你的域名。
4. 检查首页动画、点击弹层、手机端展示。
5. 确认 HTTPS 正常。

## 当前目录里哪些不用上传？

这些不用上传到服务器：

- `docs/`
- `.git/`
- `.gitignore`
- `.DS_Store`
- `个人作品文件/`
- 各类 PRD 文档

真正上线只看：

```text
index.html
assets/   # 有真实图片时才需要
```
